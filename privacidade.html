Política de Privacidade

Última atualização: 9 de outubro de 2026

Quem somos

AutoCortes é uma ferramenta de automação operada por um único responsável para publicar cortes de vídeo nos próprios canais do YouTube. Contato: tvcortessp@gmail.com.

Dados acessados

Ao autorizar o app com uma Conta do Google, o AutoCortes acessa somente:

  • permissão para enviar vídeos e editar metadados nos canais do YouTube da conta autorizada (API de Dados do YouTube);
  • estatísticas desses canais (API do YouTube Analytics).

Não coletamos dados de espectadores, contatos, e-mails ou qualquer outra informação pessoal.

Como os dados são usados

Os tokens de acesso ficam armazenados apenas no servidor do operador e são usados exclusivamente para publicar vídeos e ler métricas dos canais do próprio operador. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Uso limitado

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

O AutoCortes usa os Serviços de API do YouTube e está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

Retenção e exclusão

Os tokens permanecem armazenados enquanto o app estiver autorizado. Você pode revogar o acesso a qualquer momento em myaccount.google.com/permissions; para pedir a exclusão de qualquer dado armazenado, escreva para o e-mail de contato.
