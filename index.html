AutoCortes

AutoCortes é uma ferramenta de uso interno que produz cortes curtos de vídeos (formato vertical) e os publica nos canais do YouTube administrados pelo próprio operador, como o canal "Tudo de GTA".

O app usa a API de Dados do YouTube apenas para enviar vídeos e gerenciar metadados (título, descrição, agendamento) nos canais do operador, e a API do YouTube Analytics para ler estatísticas desses mesmos canais.
